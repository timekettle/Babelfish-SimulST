# 评测

本文说明如何复现首页的成绩：准备测试集清单、离线流式解码、打分，以及完整的对比结果。

## 1. 清单格式

每行一个 JSON：

```json
{"id": "fleurs_en_0001", "audio_path": "/data/fleurs/en_us/audio/test/0001.wav", "direction": "en2zh",
 "transcription": "原文（可选，COMET 需要）", "translations": {"zh": "参考译文（打分需要）"}}
```

- `audio_path`：16 kHz 单声道音频；
- `direction`：`en2zh` 或 `zh2en`；
- 长音频（整段录音）同样一行一条，打分时另外提供按句切分的参考（见第 3 节）。

## 2. 准备测试集

`simulst.eval.build_testsets` 生成清单：

```bash
# FLEURS（google/fleurs 的 en_us、cmn_hans_cn 目录，含 test.tsv 和解压后的 audio/test/*.wav）
python -m simulst.eval.build_testsets fleurs --fleurs-en fleurs/en_us --fleurs-zh fleurs/cmn_hans_cn --out testsets
# CoVoST 2（官方脚本生成的 test 划分 TSV + Common Voice 4 音频，mp3 自动转成 16 kHz wav）
python -m simulst.eval.build_testsets covost --covost-tsv covost_tsv --cv-root cv-corpus-4 --out testsets
# RealSI 长音频（同时生成长音频打分用的 official_inputs 和按句切开的单句版）
python -m simulst.eval.build_testsets realsi --realsi RealSI --out testsets
```

ACL 60/60、MCIF 按同样格式自备清单即可，长音频打分需要 `official_inputs`（`audio-segments.yaml` + 每种语言一个文本文件，逐行对齐）。

## 3. 解码与打分

```bash
# 解码：多条音频一起拼批；--shard/--shards 可把条目分到多张卡；首页成绩用束宽 2（--beams 2），默认是贪心 + 复读保护
python -m simulst.infer.stream --model models/Babelfish-30B-A3B --beams 2 \
  --manifests fleurs_en2zh=testsets/fleurs_en2zh.jsonl,realsi_en2zh=testsets/realsi_en2zh.jsonl --out outputs

# 单句集：BLEU、COMET（wmt22-comet-da）、LAAL / AL
python -m simulst.eval.score_sentences outputs/fleurs_en2zh
# 长音频：OmniSTEval 按参考句子重新切分后打 BLEU、chrF、COMET、StreamLAAL
python -m simulst.eval.score_longform outputs/realsi_en2zh testsets/realsi_en2zh/official_inputs
# 汇总成表
python -m simulst.eval.report outputs
```

一条命令用上所有 GPU（每张卡一个解码进程，解完自动打分）：

```bash
MODEL=models/Babelfish-30B-A3B OUT=outputs DECODE_ARGS="--beams 2" bash scripts/evaluate.sh \
  fleurs_en2zh=testsets/fleurs_en2zh.jsonl realsi_en2zh=testsets/realsi_en2zh.jsonl@testsets/realsi_en2zh/official_inputs
```

打分依赖：`pip install -r requirements/eval.txt`。

**延迟口径**：每个字的延迟是它输出时已经收到的音频长度，不含计算时间（非计算感知）。英→中按字、中→英按词（一个词在最后一个字母输出时算输出）。单句集报 LAAL，长音频报重新切分后的 StreamLAAL。实际部署时还要加上每步的计算时间，见[部署教程](DEPLOYMENT_zh.md)里的速度表。

**结果的复现性**：vLLM 把多条音频拼在一起解码时，批次组成会带来很小的数值差异，重复运行的单条结果可能有个别字不同，整体分数的波动在 ±0.001 COMET 量级。FP16 模型一次只解一条（`--max-live 1`）时结果完全确定；FP8 模型在 A800 上（Marlin 内核）即使一次一条，重复运行也有很小的差异。首页成绩是在发布的权重去掉视觉编码器之前跑的；去掉后计算上有细微的数值差别，重新运行时个别句子的措辞或出字时刻会和当时不同。
